# PC3: checklist de verificación antes de entrega

Rúbrica: CC451-2026-2-PC3.pdf, facilitada por el curso.

## 1. Reporte de avance (7 puntos)
- [ ] Historias de usuario y criterios de aceptación actualizados.
- [ ] Requisitos funcionales y no funcionales alineados al alcance real.
- [ ] Matriz de trazabilidad actualizada para PC3, indicando IMPLEMENTADO / PARCIAL / PENDIENTE.
- [ ] Enlaces específicos a código y capturas de ejecución por módulo.

## 2. Prototipo funcional al 70% (7 puntos)
- [ ] Inventario de pantallas y porcentaje explícito, verificable.
- [ ] Inventario de módulos y porcentaje explícito, verificable.
- [ ] Voz de entrada y salida probadas, o documentar limitaciones del navegador.
- [ ] LLM conectado de verdad; errores explicados.
- [ ] PWA comprobada (manifest, service worker, instalación y persistencia).
- [ ] Personalización continua, guardado y posibilidad de revertir.
- [ ] Multiusuario colaborativo real demostrado en dos sesiones.
- [ ] Diseño emocional: visceral, conductual y reflexivo con evidencias.
- [ ] Código publicado y enlazado en GitHub.

## 3. Sustentación personal (4 puntos)
- [ ] 1 video por grupo; 3 min por estudiante, hasta 9 min para 3 integrantes.
- [ ] Cada integrante demuestra su implementación y explica aporte personal.
- [ ] Video revisado íntegramente, duración verificada antes de la subida.

## 4. Calidad (2 puntos)
- [ ] README con arranque y guía de instalación reproducibles.
- [ ] C4 actualizado (actual y objetivo claramente diferenciados).
- [ ] Datos de demostración incluidos, identificados como simulados.
- [ ] LICENSE Open Source presente.
- [ ] `mi-aporte-nombre-apellido.doc` incluido (docx si el profesor lo admite, consultar de ser necesario).
- [ ] Código sin secretos, pruebas corridas y capturas verdaderas.
- [ ] ZIP y repositorio entregados antes del 11/11/2026 14:30.

**Importante:** Este checklist no da por aprobada ninguna de las casillas. Solo es la lista de validación.
